# OneInfo

Built by a developer who believes two things deserve care:
the people you love, and the code you leave behind for the next person.

Some men bring flowers. I bring clean commit messages.
(I also bring flowers. Let's not make this a competition.)

---

**How this project was made:**

Slowly. Attentively. The way you'd cook for someone on a Sunday — not because
anyone's watching, but because it should taste good.

Every function here was written like a note left on the kitchen counter:
short, kind, and useful to whoever finds it in the morning.

---

**Things this project and I have been through:**

- A 503 that only appeared when I was looking. Classic mixed signals.
- A font that refused to speak Telugu — we worked it out. She speaks it now. 🎉
- A model that got retired without a goodbye. Rude.
- One `title` field. We don't talk about the `title` field.

---

Good code, like good love, is mostly just showing up consistently
and not breaking things that were working fine.

> *Written with love, tested with suspicion.* ❤️

The unromantic-but-necessary details live in
[`frontend/README.md`](frontend/README.md) and [`backend/README.md`](backend/README.md).
Every great romance needs someone handling the logistics.
